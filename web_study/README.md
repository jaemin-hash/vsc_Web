# 마크다운 설명서

마크다운은 문서를 간단하고 가독성 좋게 작성할 수 있게 해주는 경량 마크업 언어입니다. GitHub, Notion, README 파일 등에서 자주 사용됩니다.

## 1. 제목

```markdown
# 제목 1

## 제목 2

### 제목 3
```

- `#` 개수가 많아질수록 제목의 수준이 낮아집니다.
- 보통 문서의 최상위 제목은 `#` 하나를 사용합니다.

## 2. 문단과 줄바꿈

```markdown
첫 번째 문단입니다.

두 번째 문단입니다.
```

- 문단을 구분하려면 빈 줄을 넣습니다.
- 줄바꿈을 강제로 하고 싶다면 문장 끝에 공백 두 칸을 넣거나 `<br>`을 사용합니다.

## 3. 강조

```markdown
**굵게**
_기울임_
~~취소선~~
`인라인 코드`
```

결과:

- **굵게**
- _기울임_
- ~~취소선~~
- `인라인 코드`

## 4. 목록

### 순서 없는 목록

```markdown
- 항목 1
- 항목 2
  - 하위 항목 1
  - 하위 항목 2
```

### 순서 있는 목록

```markdown
1. 첫 번째
2. 두 번째
3. 세 번째
```

결과:

## 11. 참고사항

- 마크다운은 문법이 간단해서 빠르게 작성할 수 있습니다.
- GitHub README, 문서 작성, 블로그 글, 노트 등에 많이 사용됩니다.
- 실무에서는 표, 링크, 코드 블록, 체크리스트 등을 자주 활용합니다.
